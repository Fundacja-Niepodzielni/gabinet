# POLE `ZACIESNIA|DODAJE` — hub zapisał tę lekcję jako komentarz dla czytającego
# („co najmniej połowa deklaracji musi ODMAWIAĆ czegoś, co dziś przechodzi").
# Komentarz nie ma jak zadziałać. Tutaj rodzaj jest DANĄ, którą narzędzie liczy
# i przy zestawie słabszym niż połowa ZACIESNIA — ODMAWIA STARTU.
#
# BLOK `--- BOMBA` — to jest „towarzysz", którego hub nazwał jako brakujący:
# pomiar, czy poprawiana ścieżka jest w ogóle WYKONYWANA przez suitę. Bez niego
# „zero kandydatów" (zdrowie) i „zero pokrycia" (nikt tam nie zagląda) wyglądają
# identycznie. Bomba rozdziela te dwa światy: jeśli po wysadzeniu linii NIC nie
# pada, to znaczy, że tej linii nie wykonuje żaden test — i wynik poprawy jest
# NIEROZSTRZYGNIĘTY, a nie „zdrowy".
